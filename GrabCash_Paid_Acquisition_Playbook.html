Scaling Rules

When to INCREASE Budget
  • Campaign CPA < target for 5+ consecutive days
  • CTR consistently above 2.5% on Reels / 4% on Search
  • Conversion rate on landing page > 15%
  • A new creative achieves 2X better CPA than average
  • Seasonal CPM dip (Jan-Feb, Apr-Jun)

Rule: Increase budget by max 20% per day. Never more than 50% in a week. Allow 3-4 days for learning phase after each increase.

When to DECREASE Budget
  • CPA exceeds target by 30%+ for 3 consecutive days
  • CTR drops below 1% on Meta or 2% on Search
  • Frequency exceeds 3.0 on any ad set
  • Landing page conversion rate drops below 8%
  • Seasonal CPM spike (Oct-Nov, March)

Rule: Cut underperforming ad sets by 30-50%. Pause (don't delete) campaigns with 5+ days of poor performance. Reallocate budget to better-performing segments.

Optimization Playbook — What to Do When...

When CPAs Are Rising
  1. Check creative fatigue: Are winning ads over 2 weeks old? Frequency > 3? If yes, launch 5 new creatives immediately.
  2. Check audience saturation: Has the audience been running for 3+ weeks? If yes, expand targeting or launch new LAL audiences.
  3. Check seasonal impact: Is it a high-CPM period (Oct-Nov, March)? If yes, reduce spend and shift to retargeting.
  4. Check landing page: Has LP conversion rate dropped? Run a quick speed test and check for broken elements.
  5. escalation path: Duplicate top campaigns, pause originals, restart fresh with reset learning.
When CTRs Are Dropping
  1. Immediate: Review ad preview — is the thumbnail/first-frame compelling? Test 3 new hooks.
  2. Short-term: Check if competitors launched similar campaigns (ad library check). Differentiate messaging.
  3. Medium-term: Refresh all static images and video thumbnails. Update copy with new proof points (higher earnings, more users).
  4. Test format shift: If Reels CTR is dropping, test Stories or Carousel for the same message.
When Spend Is Underpacing
  1. Check bid caps: Are cost caps too aggressive? Raise by 20%.
  2. Check audience size: Is the audience too narrow? Broaden targeting or add new interests.
  3. Check ad quality: Low relevance scores limit delivery. Improve creative quality.
  4. Add placements: Ensure all placements are enabled (Feed, Stories, Reels, Explore).
  5. Launch Advantage+ campaigns: Let Meta AI find your audience with less targeting restriction.
When a Campaign Is Crushing It
  1. Don't touch it for 48 hours: Let it stabilize. Early results can be misleading.
  2. After 48 hours of sustained performance: Increase budget by 20%. Wait 3 days.
  3. Duplicate the winning ad: Run it in a new ad set with a different audience to test scalability.
  4. Create 3-5 variations: Same concept, different hooks/CTAs. Find more winners from the same vein.
  5. Document everything: Why is it working? What's the hook, audience, format? Encode learnings for future creatives.

Scaling Playbook

When to scale, how to scale (horizontal vs. vertical), new channel expansion sequence, and the phased roadmap: ₹30-50K test → ₹1-2L validated → ₹5-7L scale (only after proven CAC).

Scaling Readiness Checklist

Do NOT scale until ALL of these criteria are met:

  • Blended CPA consistently below ₹40 for 4+ consecutive weeks
  • Activation rate (first link shared) > 30% of signups
  • At least 3 creative concepts proven with CPA < ₹35
  • Landing page conversion rate stable at > 12%
  • Retargeting funnel fully operational (3-touch sequence active)
  • GA4 + Meta Pixel + Google Tag conversion tracking all verified and matching within 10%
  • At least 500 conversions/month across all platforms for algorithm stability
  • Monthly unit economics positive: LTV (90-day) > 2.5X CPA

Horizontal vs. Vertical Scaling

Horizontal Scaling (Add more audiences/campaigns)

Lower risk. Maintains CPA stability. Preferred scaling method.

  • Launch the same winning creative to new audience segments
  • Expand to new geo-targets (new states, Tier 3-4 cities)
  • Test new ad formats with proven messaging (Reel winner → try as Carousel)
  • Add new keyword groups in Google Search
  • Create new lookalike audiences from fresh seed data
  • Launch new retargeting windows (30-day, 60-day)
Vertical Scaling (Increase budget on winners)

Higher risk. Can destabilize CPA. Requires careful monitoring.

  • Increase daily budget by max 20% per day on winning ad sets
  • Wait 3-4 days between each budget increase for learning
  • If CPA increases > 20% after scaling, revert immediately
  • Duplicate winning ad sets at higher budget (instead of editing)
  • Move from Cost Cap to Bid Cap for better spend control at scale
  • Use campaign budget optimization (CBO) to let Meta distribute across ad sets

Emergency Response Protocols

Rapid response procedures for critical paid acquisition scenarios.

EMERGENCY: Ad Account Disabled
  1. Do NOT create a new ad account (this gets you permanently banned)
  2. Submit appeal through Business Manager → Account Quality → Request Review
  3. Review ALL active ads for potential policy violations
  4. Remove any ads with aggressive income claims, misleading imagery, or clickbait
  5. Wait 24-48 hours for review. If rejected, escalate via Meta Business support chat.
  6. While waiting: Redirect budget to Google Ads and Telegram Ads
  7. Prevention: Never have more than 5% of ads disapproved. Run all creatives through policy check before launch.
EMERGENCY: CPA Spikes 2X+ Overnight
  1. Check for platform-wide issues (Meta outage, Google algorithm change)
  2. Review if a seasonal event started (sale, festival, election) inflating CPMs
  3. Pause all ad sets with CPA > 3X target immediately
  4. Check landing page: is it loading? Any broken elements? Did a deployment break conversion tracking?
  5. Verify pixel/conversion tracking: are events still firing correctly?
  6. If tracking is fine: reduce budget by 40%, focus on proven audiences only
  7. Launch 5 new creatives to test if fatigue is the cause
  8. If all else fails: duplicate best campaigns, pause originals, restart fresh
EMERGENCY: Landing Page Down
  1. Immediately pause ALL paid campaigns across all platforms
  2. Notify engineering team for immediate fix
  3. Switch ad URLs to homepage (grabcash.in) as temporary redirect
  4. Calculate wasted spend during downtime for post-mortem
  5. Once fixed: reactivate campaigns, monitor for 2 hours before leaving
  6. Prevention: Set up uptime monitoring (UptimeRobot, Pingdom) with instant alerts
SCENARIO: Budget Suddenly Available (+50%)
  1. Do NOT dump extra budget into existing campaigns (CPA will spike)
  2. Duplicate top 3-5 ad sets at 20% higher budget
  3. Launch into 2-3 new audience segments with proven creatives
  4. Allocate 30% to a new channel test (ShareChat, InMobi)
  5. Increase creative production budget proportionally
  6. Set a 2-week checkpoint: if blended CPA stays within target, continue; if rising, reduce back to original
