1. Zero Network Layer Cost

2. Lower Platform Overhead

CashKaro spends heavily on consumer acquisition (₹600 Cr revenue, still EBITDA-negative). GrabCash targets only admin acquisition — 2,000 admins vs millions of consumers. Cost per admin relationship: ₹2K-15K vs ₹50-200 per consumer.

3. War Chest Subsidy

Deploying ₹2 Cr/quarter from GrabOn reserves to subsidize above-market rates during land-grab phase. This is a time-limited investment, not a permanent cost structure. See Section 6 for war chest deployment strategy.

Master Formula Reference

1. Admin Monthly Income
= Subscribers x View Rate x CTR x Conversion Rate x AOV x Commission % x 30
2. Platform Revenue
= GMV x Average Commission Rate x Platform Take Rate
3. Admin Payout
= Order Value x Merchant Rate x (1 - Network Cut) x (1 - Platform Take Rate)
4. LTV:CAC Ratio
= (Monthly Margin per Admin x Average Retention Months) / Customer Acquisition Cost
5. Break-Even Admins
= Fixed Monthly Costs / Gross Margin per Admin = ₹30L / ₹3,000 = ~1,000 admins
6. Seasonal Revenue
= Base Monthly Revenue x Seasonal Index x War Chest Boost Factor
7. Fraud-Adjusted Revenue
= Gross Commission x (1 - Fraud Rate x (1 - Detection Rate))
8. GrabCash Commission Advantage
= (GrabCash Admin Payout - EarnKaro Admin Payout) / EarnKaro Admin Payout x 100
= (₹123 - ₹89.70) / ₹89.70 x 100 = +37.1% more per transaction
9. Earnings Per Click (EPC)
= Total Commission Earned / Total Clicks Generated
Fashion example: ₹50,000 commissions / 15,000 clicks = ₹3.33 EPC
10. Admin Churn Cost
= (Churned Admins x Avg Remaining LTV) + (Replacement CAC x New Admin Required)
100 medium admins churn: (100 x ₹1.2L remaining LTV) + (100 x ₹7,500 CAC) = ₹1.28 Cr total cost of churn
11. War Chest ROI
= (Admins Acquired x LTV) / War Chest Deployed
Q3 example: (1,000 admins x ₹36,000 avg LTV) / ₹3 Cr deployed = 1.2x direct ROI (year 1), 3.6x lifetime ROI
12. Revenue Concentration Risk (Herfindahl Index)
= Sum of (merchant share of revenue)^2 for each merchant
Target: HHI < 0.15 (diversified); Current risk: Amazon + Flipkart = 35% = HHI contribution 0.12+
Mitigation: No single merchant > 20% of total commission flow by Month 9
