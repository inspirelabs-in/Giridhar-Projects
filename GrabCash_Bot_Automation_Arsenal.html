GrabCash Telegram Bot -- Core Product

Architecture Overview

The GrabCash Telegram Bot is the flagship product of the automation toolkit. It is a webhook-based bot built on the Telegram Bot API, with a Node.js (TypeScript) backend, Redis for job queues and caching, and PostgreSQL for persistent storage. The architecture is designed for horizontal scaling, with separate microservices for link conversion, deal sourcing, analytics, and notifications.

Headline text, product image, price display format, CTA text, emoji usage, post length
Sample Size
20% of channels per variant (configurable: 10-40%)
Test Duration
2 hours default (configurable: 1-24 hours)
Primary Metric
Click-through rate (clicks / views)
Secondary Metrics
Conversion rate, revenue per click, engagement rate
Min Statistical Significance
95% confidence level before auto-selecting winner
Fallback
If neither variant reaches significance, send original (Version A) to remaining channels

Deal Scoring Algorithm -- Full Specification

function calculateDealScore(deal) { const weights = { discount: 0.25, priceVsATL: 0.20, brandPopularity: 0.15, productRating: 0.10, categoryConversion: 0.10, expiryUrgency: 0.10, commissionRate: 0.10 }; let score = 0; // Discount score: 0% = 0, 50% = 50, 80%+ = 100 score += weights.discount * Math.min(deal.discountPercent / 0.8, 1) * 100; // Price vs ATL: at ATL = 100, 20% above ATL = 50, 50%+ above = 0 const atlRatio = (deal.currentPrice - deal.allTimeLow) / deal.allTimeLow; score += weights.priceVsATL * Math.max(0, (1 - atlRatio * 2)) * 100; // Brand popularity: S=100, A=75, B=50, C=25 const brandScores = { S: 100, A: 75, B: 50, C: 25 }; score += weights.brandPopularity * (brandScores[deal.brandTier] || 25); // Product rating: 5.0=100, 4.0=75, 3.0=50, below 3.0=0 score += weights.productRating * Math.max(0, (deal.rating - 3) / 2) * 100; // Category conversion rate: normalized to 0-100 score += weights.categoryConversion * (deal.categoryConversionRate / 0.15) * 100; // Expiry urgency: <4hrs=100, <24hrs=70, >7days=20 const hoursRemaining = deal.hoursUntilExpiry; let urgencyScore = hoursRemaining < 4 ? 100 : hoursRemaining < 24 ? 70 : hoursRemaining < 168 ? 40 : 20; score += weights.expiryUrgency * urgencyScore; // Commission rate: normalized (20% = 100) score += weights.commissionRate * Math.min(deal.commissionRate / 0.20, 1) * 100; return Math.round(score); }

Anti-Fraud & Quality Control

Fraud Detection Layers

Anti-fraud is critical for maintaining merchant trust and GrabCash's reputation. The system operates as a multi-layered defense that catches fraud at the click, conversion, and payout stages.

Fraud Type Detection Matrix

Fraud TypeDetection MethodSignalActionFalse Positive Rate
Fake Clicks IP fingerprinting + click velocity analysis >5 clicks from same IP/fingerprint in 1 hour on same link Flag clicks as bot; exclude from metrics; warn admin <2%
Self-Purchase IP matching between admin's registered IPs and purchaser IP Conversion from IP matching admin's known IPs/devices Flag conversion; manual review; deduct commission if confirmed <5%
Cookie Stuffing Click-to-conversion time analysis + referrer chain inspection Conversion with no genuine click, or click from hidden iframe Reject conversion; flag admin account <1%
Bot Traffic User-agent analysis + JavaScript challenge + behavioral patterns Non-browser user agent, no JS execution, inhuman click patterns Block traffic; exclude from metrics <3%
Click Farms Geographic clustering + device fingerprint diversity analysis Many clicks from same geo/ASN with similar fingerprints Quarantine clicks; investigate admin; suspend if confirmed <5%
Return Fraud Post-purchase monitoring (merchant callback for returns) >30% return rate on admin's conversions Warning at 30%, account review at 50%, suspension at 70% <1%

Merchant Protection Guarantees

  • Click Quality Guarantee: GrabCash guarantees <5% invalid click rate across all admin traffic. If exceeded, affected clicks are excluded from billing.
  • Return Rate Monitoring: Admins with abnormally high return rates are flagged and investigated.
  • Brand Safety: Content posted by admins is periodically audited. Misleading claims, fake scarcity, or deceptive urgency results in warnings and eventual suspension.
  • Cookie Compliance: All affiliate cookies set via GrabCash are first-party, compliant with India's upcoming data protection regulations.
