Referral Program Design

💰 Two-Tier Referral System

Tier 1 — Direct Referral: Referrer gets ₹50 when their referred user completes first earning. Referred user gets ₹25 bonus on first earning. Both unlock immediately — no complicated conditions.

Tier 2 — Ongoing Commission: Referrer earns 5% of their referred user's commissions for the first 6 months. This creates a "team building" incentive — power users recruit and mentor new users because they earn from their success.

🏆 Milestone Bonuses

Gamify referrals with escalating rewards:

  • 5 referrals: ₹500 bonus + "GrabCash Ambassador" badge
  • 25 referrals: ₹3,000 bonus + priority support + early deal access
  • 100 referrals: ₹15,000 bonus + featured on GrabCash homepage + dedicated account manager
  • 500 referrals: ₹1,00,000 bonus + GrabCash Star Partner status + custom commission rates

Anti-Fraud Referral Safeguards

🚨 Fraud Signals (Auto-Flag)

  • Same IP / device ID for referrer + referred user
  • Referred users all have similar email patterns (john1@, john2@, john3@...)
  • 10+ referrals from single user with 0% activation (referred users never earn)
  • Referral spike from an unusual geography (VPN detection)
  • Same UPI account linked across multiple "referred" accounts
  • Referral code shared on cashback/reward-farming forums or Telegram groups

✅ Fraud Prevention Rules

  • Referral reward paid ONLY after referred user completes first real earning (not just signup)
  • Minimum earning threshold: referred user must earn ₹20+ before reward unlocks
  • Device fingerprinting: block rewards if same device created both accounts
  • Daily referral cap: max 10 successful referrals per user per day (legitimate users never hit this)
  • 72-hour cooling period: reward not instant — allows time for fraud review
  • Referred user must remain active for 7 days post-signup to confirm reward

Viral Coefficient Math — How We Get to K > 1

Viral Coefficient Formula: K = (invites sent per user) × (conversion rate of those invites)

Current Target: K = 2.5 invites × 20% conversion = 0.50 (sub-viral, but contributes 30% of growth)
Optimistic Target (Month 6+): K = 4 invites × 25% conversion = 1.0 (viral — self-sustaining growth)

Levers to improve K:
• Increase invite volume: make sharing easier (one-tap), trigger at more moments (every payout, every milestone, every deal shared)
• Increase conversion: better earning proof in shares, personalized landing pages, instant gratification for signee
• Reduce friction: no app download required to start, instant signup via phone number, see first deal within 10 seconds

📈 Testing Methodology

  • Batch size: Minimum 10 new creatives per week (5 for Meta, 3 for YouTube, 2 for Google Display)
  • Minimum spend before kill: ₹1,500/creative (need statistical significance, ~200 impressions minimum for video)
  • Kill criteria: CTR < 0.8% after ₹1,500 spend, OR CPI > 2x target after 50 installs
  • Scale criteria: CTR > 1.5% AND CPI < target for 3 consecutive days → increase budget 50%
  • Fatigue detection: If top creative's CTR drops 30%+ from peak → immediate replacement (typical lifespan: 7-14 days in this niche)
  • Winner analysis: Every creative that hits < ₹30 CAC → document: what hook, what format, what audience, what day/time. Feed back into next batch brief.
  • Losing pattern analysis: Monthly review of all killed creatives — find the pattern. What consistently doesn't work? Stop making those.
